# `docs/provenance.md` is the SoT for *which* third-party work is in this tree
# and *why* each obligation applies. This file is the machine-checkable half:
# one line per claim that document makes about a file, so that the claim cannot
# quietly stop being true. `tools/provenance-gate.sh` reads it.

# The obligations became live on 2026-08-16, when the repository went public and
# Apache-2.0 §4 fired (provenance.md §4). Every one of them was paid before that
# — this gate is what keeps them paid.

# Format: <path> : <substring that must appear somewhere in the file>
# A file may have several lines; all of them must hold.
