## 1. 再現率 (受け入れオラクル = experiments/stage4c/coverage.ts)

母数は doc-gen4 がディスクに出した 348 ページ = 22,028,728 B。領域は隙間なくページを覆う
(coverage.ts のタイル検査が通っている)。「再現」= その領域が **byte 完全一致**したもの。

| | schema 2 | schema 3 | |
|---|---:|---:|---|
| 再現できたバイト | 14,007,303 | **21,258,979** | +7,251,676 |
| 再現率 | 63.587% | **96.506%** | +32.919 pt |
| byte 完全一致したページ | 34 / 348 | **148 / 348** | +114 |
| `decl_header` 領域一致 | 2,705 / 3,477 | **3,477 / 3,477** | |
| `equations` 領域一致 | 452 / 653 | **653 / 653** | |

ログ: `stage7a-coverage.txt` (schema 3) / `stage7-coverage-baseline.txt` (schema 2)。

### 原因別の未再現バイト

| 原因 | schema 2 | 母数比 | schema 3 | 母数比 | 領域数 |
|---|---:|---:|---:|---:|---:|
| **splitWhitespaces — IR schema 2 の既知欠落** | **7,251,676** | 32.919% | **0** | 0% | 973 → 0 |
| docstring の autolink 索引が IR に無い | 401,987 | 1.825% | 401,987 | 1.825% | 208 |
| IR に情報が無い (メンバの binder / docstring) | 135,078 | 0.613% | 135,078 | 0.613% | 33 |
| CommonMark 未実装 | 120,261 | 0.546% | 120,261 | 0.546% | 47 |
| 設定値 (rev) — IR に無い | 108,772 | 0.494% | 108,772 | 0.494% | 540 |
| IR に情報が無い (領域ごと欠落、`div.attributes`) | 3,651 | 0.017% | 3,651 | 0.017% | 89 |
| **合計** | **8,021,425** | 36.413% | **769,749** | 3.494% | |

**splitWhitespaces 以外の 5 原因は 1 バイトも動いていない。** 増えた 7,251,676 B は
splitWhitespaces 原因の 7,251,676 B と**完全に一致**する — 他を壊さずにこの原因だけを
閉じたことの確認であって、レンダラ全体が良くなったという意味ではない。

ログ: `stage7a-coverage-breakdown.txt` (§X1 原因×領域、§X2 ページ別)。

### 帰属が全か無かであることの内訳

schema 2 のページと schema 3 のページを突き合わせると、**長さはどこも同じで、
違う UTF-16 code unit は 2,725 個**、すべて改行 → スペース。この 2,725 文字が
7,251,676 B (母数の 32.9%) を 0 点から満点に動かした。

2,725 = render.ts の `wsWidthChars` 2,461 (decl_header 経路) + 264 (ページ経路)。
ログ: `stage7a-render-stats.txt`、`stage7a-pitfall-recheck.txt` の (d)。

## 3. 幅そのものの統計 (experiments/stage7a/check-spans.ts, ログ `stage7a-checkspans.txt`)

| | |
|---|---:|
| `kind 1` (const) span | 142,181 |
| うち front/back を持つ | 29,248 (20.57%) |
| 記述している空白の UTF-16 単位 | 75,318 |

| 空白の run (front + back) | 54,742 |
| … maximal でない (タグの外に空白が続く) | 0 (0.00%) |

そして **stage4c の `--ws-heuristic` が壊していた母数**:

| | |
|---|---:|
| run を持たないのに隣に空白がある const span の辺 | 135,316 |
| … run 丸ごとを塗る推測が誤って書き換える単位 | **8,403** |

正しく書き換えるべき 3,417 単位に対し、推測は 8,403 単位を巻き添えにしうる。
これが「407 直して 100 壊す」の正体で、**幅が無い限り推測では閉じない**。

## 4. 再現手順

```sh
# 抽出 (schema 3)
experiments/stage7a/build.sh
experiments/stage7a/run.sh stage7a-tag-1 -- \
  --equations --refs --tagged-code --write-ir --ir-dir <IR_DIR>   # 6 回、run 1 は cold

# 生成 — 採点用は必ず具体的な rev を埋めた --source-url で描く
deno run --allow-read --allow-write --allow-env experiments/stage7a/render.ts \
  --ir <IR_DIR> --pages <PAGES> \
  --source-url https://github.com/FujiHaruka/information-theory/blob/573793b243fb1343636088eb62d1789ab2b14cec \
  --stats <STATS>

# 採点 (--ws-heuristic は stage7a には存在しない)
deno run --allow-read --allow-write --allow-env experiments/stage4c/coverage.ts \
  --pages <PAGES> --report <OUT>
deno run --allow-read --allow-write --allow-env benchmarks/tools/coverage-breakdown.ts \
  --pages <PAGES> --report <OUT>

# IR の不変条件
deno run --allow-read experiments/stage7a/check-spans.ts --ir <IR_DIR>
```
