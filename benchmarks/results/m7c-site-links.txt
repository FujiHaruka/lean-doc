Why the 22,817 are not disagreements 【実測 M7-a, restated here】
----------------------------------------------------------------
69 distinct URLs, and for every one of them the .lidx name at that range is a
structure field or an inductive constructor whose **parent** the oracle does
hold. doc-gen4 renders those inside the parent's `decl` div — as
`<li class="structure_field">` or inside `Instances For` — so it writes no
`gh_link` of their own and the miner has nothing to compare against. The five
most frequent are, by name:

  Init.Prelude  110-111  Bool.true                          (a constructor)
  Init.Prelude 1280-1280 LE.le                              (a class field)
  Init.Prelude 1359-1359 HAdd.hAdd                          (a class field)
  Init.Prelude 1746-1746 Membership.mem                     (a class field)
  Init.Core     578-578  EmptyCollection.emptyCollection    (a class field)

They are the commonest constants in a signature (`+`, `≤`, `∈`), which is why
69 URLs account for 22,817 of the 94,855 anchored hrefs. Grepping the reference
page for the anchor confirms it: `#L110-L111` does not occur anywhere in
Init/Prelude.html.

The 7 that stayed relative
--------------------------
All seven are `nameToLink?`'s **first branch**, which is not one of M7-c's call
sites and does not live in this crate: a docstring word that ends in `.lean` and
contains a `/` is a *source path*, and `lean_doc_md::Renderer::resolve_link`
answers it before the name resolver is consulted (see the heading of
`crates/lean-doc-render/src/autolink.rs`). It maps
`Mathlib/…/ChainRule.lean` -> `<root>Mathlib/…/ChainRule.html` without ever
naming a module, so `ExternalLinks::href` is never reached. Converting it needs a
path -> module rule, which is a different function from the one M7-c added.

  96,331 of 96,338 links whose destination is a dependency became blob URLs.

Not M7's, and unchanged by it: 7,354 relative hrefs to `foundational_types.html`
(a doc-gen4 artifact page this site does not write — `SpanKind::Sort`'s target is
a hard-coded name, not a module) and 153 relative hrefs to partial own-package
module names. Both are byte-identical in site-before.
