4. 本物の出力が見つけた欠陥 2 件 — プレビューでは出なかった
----------------------------------------------------------
  手書きプレビュー (design/preview/module.html) は計測対象から取った
  structure / def / theorem の 3 形しか持たない。**そこで完成に見えた CSS が、
  e2e/micro の 43 宣言で 2 つ壊れた**:

  (a) `class inductive` — kind の語が gutter (5rem) より広く、
      `white-space: nowrap` のせいで宣言名に**重なった**。
      → gutter 内で折り返す。最長の kind 1 個のために全ページの gutter を
        広げることはしない。

  (b) binder が 0 個の宣言 (`Micro.Named : Type`) — 分けるべき文脈が無いのに
      罫線が引かれ、**空の箱に蓋**が乗った。
      → `.sig:not(:has(> .binder))` でコロンをインラインに戻す。
        `:has()` の無いブラウザではブロックのまま = 空なだけで壊れてはいない。

  (c) `noncomputable def` — **e2e/micro でも出なかった**。出したのは計測対象の
      422 モジュールで、kind の語が gutter (5rem) に入らず `NONCOMPUTA` /
      `BLE DEF` と**単語の途中で折れた**。対象の **505 宣言**がこの kind。
      → gutter を最長の**語** (`noncomputable`) に合わせて 6.25 → 7.75rem。
        最長の**句** (`noncomputable instance`) には合わせない — 句は空白で折れる。

  **3 件とも同じ形**: 代表的な入力で完成に見えた版が、母数を増やすと壊れる。
  プレビュー 3 形 → fixture 43 宣言 → 対象 4,584 宣言と広げるたびに 1 件ずつ出た。

  対象が出す kind は 9 種【実測】:
      theorem 3,517 / noncomputable def 505 / def 225 / instance 88 /
      structure 37 / abbrev 16 / noncomputable abbrev 4 / opaque 1 /
      noncomputable instance 1
