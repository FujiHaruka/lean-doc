4. 本物の出力が見つけた欠陥 2 件 — プレビューでは出なかった
----------------------------------------------------------
  手書きプレビュー (design/preview/module.html) は計測対象から取った
  structure / def / theorem の 3 形しか持たない。**そこで完成に見えた CSS が、
  e2e/micro の 43 宣言で 2 つ壊れた**:

  (a) `class inductive` — kind の語が gutter (5rem) より広く、
      `white-space: nowrap` のせいで宣言名に**重なった**。
      → gutter 内で折り返す。最長の kind 1 個のために全ページの gutter を
        広げることはしない。

  (b) binder が 0 個の宣言 (`Micro.Named : Type`) — 分けるべき文脈が無いのに
      罫線が引かれ、**空の箱に蓋**が乗った。
      → `.sig:not(:has(> .binder))` でコロンをインラインに戻す。
        `:has()` の無いブラウザではブロックのまま = 空なだけで壊れてはいない。

  **どちらもプレビューだけ見ていたら出ていない。** e2e/micro が
  「対象が持たない形」を持っている理由がそのまま効いた回。
