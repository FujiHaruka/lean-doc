The floor is not the whole story: a cache has to be read and written, and
that cost is not in this table because it does not exist in the program
being measured. The ceiling this gives is therefore an upper bound on the
saving, and the A/B in `run.sh` is what says how much of it survives.

A caveat that cuts the other way: `delta-miss` shows the scan is already
skipped when no name moved (0.0681 s vs 0.1912 s), so on a run
that changes no name the removable part is smaller by that much.
